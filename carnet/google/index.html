Script Google du Carnet EPS

Une seule fois, sur un ordinateur : ton carnet se copiera ensuite tout seul dans un tableau de ton Google Drive.

  1. Ouvre sheets.new (connecté à ton compte Google) : un tableau vide se crée sur ton Drive. Nomme-le « Carnet EPS ».
  2. Menu Extensions › Apps Script. Efface tout ce qui s'y trouve.
  3. Touche 📋 Copier le script ci-dessous, colle-le dans Apps Script, puis 💾 Enregistrer. Rien à modifier dedans.
  4. Déployer › Nouveau déploiement, roue dentée › Application Web. Exécuter en tant que : Moi. Qui a accès : Tout le monde. Touche Déployer, puis Autoriser l'accès (choisis ton compte ; si Google affiche « Google n'a pas validé cette application », touche Paramètres avancés › Accéder à … (non sécurisé) : c'est ton propre script).
  5. Copie l'URL de l'application Web (elle finit par /exec) et envoie-la-toi (mail, WhatsApp).
  6. Sur ton téléphone : Carnet › ⚙️ Réglages › Sauvegarde › Google Drive. Colle l'adresse, garde le code proposé et touche Lier à mon Google Drive.
